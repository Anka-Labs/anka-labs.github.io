Changelog

[1.3.1] - 2026-10-10

  • First Asset Store release. The Asset Store version installs into Assets/Tessera/ and includes a demo scene (Samples/Tessera Demo.unity) with the sample assembly imported by drag and drop and loaded with CadLoader.
  • Requires Unity 6.2 (6000.2) or later.
  • CadLoader and CadImportApi without a log callback only write warnings and errors to the console.

[1.3.0] - 2026-10-10

  • Renamed to Tessera. Package vonanka.tessera, menu Tools ▸ Tessera CAD Importer, Project Settings ▸ Tessera. Breaking: namespaces Tessera.CadImport and Tessera.CadImport.Editor, assemblies with the same names, and types renamed from Step* to Cad* (CadImportApi, CadImportSettings, CadImportException, CadLoader, CadLoadOptions, CadModel, CadAssetImporter). Files already imported by drag and drop keep their settings. Default folders are now Assets/CAD Imports and Assets/CAD Imports/Materials.
  • CAD color names that are only a number (Siemens NX palette numbers such as "16841") are ignored; those materials are named and shared by color instead ("Color 33FFCC").
  • The warning for files without colors no longer claims that AP203 cannot store colors.
  • Verified with STEP AP203, AP214 and AP242 files from Creo, SolidWorks, Autodesk and Siemens NX (NIST D2MI models).
  • The sample assembly is now testmachine.step / testmachine.igs.
  • The converter is now a native library (step2glb.dll) that the editor loads in-process, instead of a separate executable. The package no longer contains any .exe files. Imports, settings and results are unchanged.
  • Cancelling now also stops Open CASCADE while it is reading or meshing a large file, not only between steps.
  • Path override in the window now expects a step2glb.dll.
  • Updating the converter DLLs requires restarting Unity, since a loaded library cannot be replaced.
  • Runtime import on Windows: CadLoader.LoadAsync loads STEP/IGES files in play mode and in Windows x64 players. Enable Project Settings ▸ Tessera ▸ Include in Windows builds to ship the converter with a build. Destroying the returned CadModel frees its meshes and materials.
  • CadLoadOptions.materialTemplate / transparentMaterialTemplate: new materials can be copies of your own materials instead of the pipeline's Lit shader. This also works for editor imports through the scripting API.
  • The package now has a runtime assembly. CadImportException, MeshQualityPreset, UpAxis and RenderPipelineTarget are in the runtime namespace Tessera.CadImport.

[1.2.0] - 2026-10-04

  • Materials are named after the CAD appearance when the file has one (e.g. Autodesk's "Steel - Satin"), otherwise after the color ("Color A0A0A0"). Parts with the same appearance share one material.
  • Material library (Assets/StepImports/Materials by default): materials are saved there once and reused by every model, so they only need to be set up once. Drag-and-drop imports use library materials when they exist; Extract Materials in the importer Inspector copies the embedded ones into the library.
  • Appearance names set the look: metals (steel, brass, aluminium …) become metallic, and matte/satin/glossy set the smoothness. English, German and Swedish terms are recognized.
  • Fix: plain CAD colors were rendered as fully metallic, because Open CASCADE omits the metallic factor and glTF then defaults to 1.
  • Repeated parts under the same parent get unique names (PART, PART (1), …), which removes Unity's "Identifier uniqueness violation" warning and keeps references to individual instances stable on re-import.
  • A warning is shown when a file contains no colors, e.g. STEP AP203 exports, with a hint to re-export as AP214/AP242.

[1.1.0] - 2026-10-04

  • Drag and drop: .step, .stp, .iges and .igs files placed in the project are imported automatically as models (meshes and materials as sub-assets), with import settings in the Inspector and re-import when the file changes.
  • IGES support in the converter, the window and the scripting API.
  • The converter now links Open CASCADE dynamically (TK*.dll next to step2glb.exe) so the LGPL library can be replaced, and ships the MSVC runtime app-local. Full license texts are included in Third Party Licenses/.
  • The converter DLLs are excluded from the editor and all build targets.

[1.0.0] - 2026-10-04

  • First release: STEP import with assembly hierarchy, CAD colors, tessellation presets, vertex welding, UVs, tangents, Standard/URP/HDRP materials, prefab or combined mesh output and a scripting API (StepImporterApi).
  • Converter step2glb for Windows x64, built with Open CASCADE 8.0.1.
