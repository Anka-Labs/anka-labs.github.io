Tessera – STEP & IGES CAD Importer

Imports CAD files in STEP (.step / .stp) and IGES (.iges / .igs) format as Unity models, with the assembly hierarchy, CAD colors and materials for the Built-in Render Pipeline, URP or HDRP.

Tessellation is done by a bundled converter built on Open CASCADE. No other software or packages need to be installed.

Requires Unity 6.2 (6000.2) or later. Works with the Built-in Render Pipeline, URP and HDRP. The converter is available for the Windows (x64) editor and, for runtime import, Windows x64 players.

Installation

Asset Store: open Window ▸ Package Manager ▸ My Assets, select Tessera and click Import. Everything is placed in Assets/Tessera/; the demo scene is Assets/Tessera/Samples/Tessera Demo.unity.

Package Manager (git): open Window ▸ Package Manager ▸ + ▸ Install package from git URL… and paste:

https://github.com/vonAnka/step_importer.git?path=/Packages/vonanka.tessera#v1.3.1

Replace #v1.3.1 with the version you want. Without it, you follow the latest commit on the default branch.

Local folder: + ▸ Install package from disk… and select package.json in this folder.

.unitypackage: import the file through Assets ▸ Import Package ▸ Custom Package….

Getting started

There are two ways to import:

Drag and drop: drag a .step, .stp, .iges or .igs file into the Project window. It is imported as a model, like an FBX file, and can be dragged straight into the scene.

  • Select the file to change the import settings in the Inspector, then click Apply.
  • When you save a new version of the file from your CAD tool, it is re-imported automatically.
  • Meshes and materials are stored inside the file and are read-only, as with FBX. To edit materials, use Extract Materials (see Materials) or the window.

The window (Tools ▸ Tessera CAD Importer) is for files outside the project and when you want editable output:

  1. Click Check converter. The log should show step2glb 2.0 (Open CASCADE …).
  2. Select a CAD file and click Convert. The result is a prefab with a separate mesh asset in Assets/CAD Imports/.

IGES files have no assembly structure, so they become a single part with colors.

Want something to try? Open the demo scene in Assets/Tessera/Samples/ (Asset Store version), or import the Test assembly sample from the Samples tab in the Package Manager (git version). The demo shows the sample assembly imported by drag and drop, and the same file loaded with CadLoader when you press Play.

Settings

Setting Meaning
CAD up axis The axis that points up in the CAD model (Z or Y). The model is rotated to Unity's Y-up.
Mesh quality Draft / Medium / High / Ultra, or Custom with your own values.
Chordal error (mm) Maximum distance between the exact CAD surface and the triangles. Lower values give more triangles.
Angular tolerance (°) Maximum angle between the normals of adjacent triangles. Controls how round small radii become.
Weld vertices Closes the seams between CAD faces. Sharp edges are kept via Max normal angle.
Generate UVs Box projection in metres (UV tile size), suitable for tiling textures.
Lightmap UVs Generates UV2. Slow on large models.
Use CAD colors Creates materials from the colors and appearances in the CAD file. When off, everything gets the same gray material.
Render pipeline Auto picks Standard, URP Lit or HDRP Lit based on the project's pipeline.
Material library Shared folder for materials, Assets/CAD Imports/Materials by default. See Materials below.
Format (window) Prefab keeps the hierarchy. Combined mesh bakes everything into one .asset.
Triangle warning (window) Asks before building models with more triangles than this.

Prefab mode creates <name>.prefab and <name>_Meshes.asset. Materials are stored in the material library.

Materials

Names: materials are named after the appearance in the CAD file when there is one, for example Steel - Satin or Plastic - Matte (White) from Autodesk Inventor/Fusion. Otherwise they are named after the color, for example Color A0A0A0. All parts with the same appearance share one material.

The material library is a folder shared by all models:

  • The window saves new materials there and reuses the ones that already exist. Set up Steel - Satin.mat once, with textures, metallic and so on, and every model with that appearance uses it, including future imports.
  • Drag-and-drop imports use library materials that already exist. Others are embedded in the CAD file and are read-only. Click Extract Materials in the Inspector to move them into the library, where they become editable.

Appearance: some words in the material name set up the material. Metals (steel, stainless, brass, aluminium, chrome, copper …) become metallic, and matte/satin/glossy set the smoothness. English, German and Swedish terms are recognized.

Which names are available depends on the CAD tool. Autodesk tools export appearance names, while SolidWorks, for example, exports only colors. STEP AP203 contains neither colors nor names.

Scripting API

Imports can be run from your own editor scripts, for example in batch mode or CI:

using Tessera.CadImport.Editor;

var settings = new CadImportSettings
{
    sourcePath = @"C:\CAD\machine.step",
    outputFolder = "Assets/CAD",
    quality = MeshQualityPreset.High,
    instantiateInScene = false,
};
settings.ApplyPreset();

ImportResult result = await CadImportApi.ImportAsync(settings);
Debug.Log($"{result.AssetPath}: {result.TriangleCount} triangles");

Errors are thrown as CadImportException. Cancelling through a CancellationToken throws OperationCanceledException.

CadImportSettings, CadImportApi and ImportResult are in the Tessera.CadImport.Editor namespace. The shared types CadImportException, MeshQualityPreset, UpAxis and RenderPipelineTarget are in Tessera.CadImport.

Runtime import (Windows)

CadLoader loads CAD files while the game runs: in the editor's play mode, or in a Windows x64 player.

using Tessera.CadImport;

public class CadViewer : MonoBehaviour
{
    public Material template; // e.g. a URP Lit material; new materials are copies with the CAD color

    async void Start()
    {
        var options = new CadLoadOptions { quality = MeshQualityPreset.Medium, materialTemplate = template };
        CadModel model = await CadLoader.LoadAsync(@"C:\CAD\machine.step", options,
            onProgress: (p, status) => Debug.Log($"{p:P0} {status}"));
        Debug.Log($"{model.TriangleCount} triangles");
        // Destroy(model.gameObject) also frees the model's meshes and materials.
    }
}
  • Builds: enable Project Settings ▸ Tessera ▸ Include in Windows builds. The converter (step2glb.dll and Open CASCADE, about 40 MB) and its license texts are then copied into <Game>_Data/Plugins/x86_64/ of Windows x64 builds. Other builds are unaffected.
  • Materials: a build only contains shaders that something in it uses. Assign materialTemplate (and optionally transparentMaterialTemplate) so that the shader is included. Without a template, the pipeline's Lit shader must be in the build anyway, or listed under Graphics ▸ Always Included Shaders.
  • Threads: call LoadAsync from the main thread. Open CASCADE and mesh processing run in the background, and GameObjects are created over several frames. Conversions run one at a time.
  • Licenses: Open CASCADE is licensed under the LGPL. A game that ships the converter must include the notices that are copied next to it (step2glb-licenses/) and must not prevent users from replacing the DLLs.
  • CadLoader.IsSupported is false on other platforms. Lightmap UVs are not generated at runtime.

Troubleshooting

Symptom Cause / fix
The step2glb converter library was not found There is no converter for this platform (macOS/Linux), or the Tools/ folder is missing from the installation.
Could not load the converter library A DLL next to step2glb.dll in Tools/win-x64/ is missing or damaged. Reinstall the package.
The CAD file could not be read The file is not valid STEP (ISO-10303-21) or IGES. Try exporting it again from the CAD tool.
Warning could not be tessellated A part has broken geometry. It is kept as an empty node; the rest of the model is imported.
All parts are gray The file has no colors. STEP AP203 cannot store colors: export as AP214 or AP242 instead (in Creo: step_export_format).
The model lies on its side The model was designed with a different up axis. Switch CAD up axis between Z and Y; it varies between CAD tools and models.
The model is 1000 times too large or small The CAD file declares the wrong unit. Scale it in Unity, or export again with the correct unit.
HDRP materials look wrong Select the materials once in the Inspector so that HDRP updates them.

Limitations

  • Textures and PMI/annotations from STEP are not imported, only geometry, structure and color.
  • Colors assigned at instance level in deeply nested assemblies may be lost.
  • The converter is currently available for Windows x64 only.
