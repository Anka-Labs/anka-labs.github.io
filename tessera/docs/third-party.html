Open CASCADE Technology 8.0.1

  • Files: Tools/win-x64/TK*.dll (unmodified, dynamically linked by step2glb.dll)
  • License: GNU Lesser General Public License v2.1 with the Open CASCADE Exception (Third Party Licenses/OpenCASCADE-LICENSE_LGPL_21.txt, Third Party Licenses/OpenCASCADE-OCCT_LGPL_EXCEPTION.txt)
  • Source code: https://github.com/Open-Cascade-SAS/OCCT/tree/V8_0_1, built with the vcpkg port opencascade (features: rapidjson)

You may replace the TK*.dll files with your own build of Open CASCADE 8.0.x (same toolkits, x64, MSVC runtime /MD); step2glb.dll loads them from its own folder. Restart Unity after replacing them.

With Include in Windows builds enabled, the same files are copied into Windows player builds (<Game>_Data/Plugins/x86_64/), together with this notice and the license texts (step2glb-licenses/).
